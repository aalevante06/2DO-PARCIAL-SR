# Configuraciones publicables

Los ficheros Cisco son extractos del `show running-config` aportado por el estudiante, sanitizados. El FortiGate se ha generado desde el backup real FortiOS aportado, extrayendo exclusivamente las secciones relevantes. Se han omitido contraseñas, hashes, PSK, secretos, UUIDs y comunidades.

**No son backups completos restaurables.** El backup original contiene `set password ENC` y `set psksecret ENC`: nunca subirlo sin sanear.
